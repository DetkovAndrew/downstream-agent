# Downstream Agent

Локальный агент для сравнения нефтегазовых компаний по отчётности и новостям:
собирает отчёты и новости, распознаёт PDF, достаёт показатели (ROACE, ROCE, ROE, выручка,
загрузка НПЗ и др.) и собирает сводную таблицу Excel. Ответы на вопросы даёт только с цитатой,
которая дословно есть на странице источника. Ничего не считает и не додумывает: нет цитаты,
значит, нет значения.

Список компаний (36) и источников задаётся в `companies.toml`. Все данные берутся из открытых источников.

## Состав

- `downstream_agent/` --- пакет: `collector` (сбор), `discover` (поиск отчётов с LLM), `newsfeeds`, `newsheet` (таблица новостей),
  `recognize` (PDF и OCR), `extract` и `sheet` (показатели), `ask` (вопросы с цитатами), `llm` (провайдеры), `app` (локальный сервер) и `web/` (интерфейс).
- `ui.py` --- интерфейс на Streamlit; `app_entry.py` --- точка входа для сборки `.exe`.

## Запуск

```bash
python -m pip install -r requirements-server.txt
cp .env.example .env          # вставьте свои ключи, в репозиторий они не попадают
python -m downstream_agent.app    # локальное приложение, откроется браузер
python -m downstream_agent --help # команды: collect, discover, news, ask, sheet, newsheet, ui
```

Поддерживаются провайдеры LLM: Gemini, YandexGPT, GigaChat и локальные модели (см. `.env.example`).
Для OCR нужен установленный Tesseract.

## Безопасность

`build_exe.bat` вшивает `.env` в `.exe`, если файл лежит рядом. Не распространяйте такой `.exe`.
Каталоги `data/` и `outputs/` не хранятся в репозитории.
